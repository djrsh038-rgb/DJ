# 💰 배당 포트폴리오 트래커 (무료, GitHub Pages용)

API 키나 서버 없이, 국내·해외 주식/ETF 배당 포트폴리오를 관리하는 웹페이지입니다.

## 배포 방법

1. GitHub에 새 저장소(Public)를 만듭니다.
2. 이 폴더의 `index.html`을 저장소 루트에 업로드합니다.
3. 저장소 **Settings → Pages**에서 브랜치를 `main`(또는 `master`) / `/root`로 설정 후 저장합니다.
4. 1~2분 후 `https://<사용자이름>.github.io/<저장소이름>/` 주소가 생성됩니다. 이 링크를 공유하면 누구나 로그인/키 입력 없이 바로 사용할 수 있습니다.

## 특징

- **종목 검색으로 데이터 자동 취합**: 회사명이나 티커를 검색창에 입력하면 Yahoo Finance 검색 엔드포인트로 국내·해외 종목을 함께 찾아주고, 결과를 클릭하는 즉시 시세·PER·PBR·주당배당금을 조회해 입력 필드에 자동으로 채워 넣습니다. 검색이 안 되면 필드에 직접 입력해도 됩니다.
- **국내·해외 종목 관리**: 코스피/코스닥, 미국 시장의 주식·ETF를 함께 등록하고 보유 수량을 입력합니다.
- **시세 자동조회**: Yahoo Finance 공개 엔드포인트로 현재가를 자동 조회합니다(국내는 `.KS`/`.KQ` 접미사 사용). 수동 새로고침, 30초/1분/5분 자동 갱신을 지원합니다.
- **재무지표 자동조회**: 종목 추가 시 함께 채워지며, 아래 "자동조회 3단계"를 순서대로 시도합니다.
  - `data.json` 사전 캐시(감시 목록에 등록된 종목): yfinance로 가져온 시세·PER·PBR·배당성향·부채비율·(가능한 경우) 총자산까지 포함
  - 국내(Naver Finance 직접/Worker 경유): PER·PBR·주당배당금
  - 해외(Yahoo Finance 직접/Worker 경유): PER·PBR·배당성향·부채비율·(가능한 경우) 총자산
  - `data.json`에 없고 국내 종목인 경우 배당성향·부채비율·총자산은 무료 자동조회 소스가 없어 종목 "상세" 영역에서 직접 입력합니다.
  - 자동조회가 실패하면(브라우저 정책, API 상태 변화 등) 언제든 표에서 직접 값을 입력/수정할 수 있습니다.
- **자동조회 실패 시 검색 링크로 바로 찾기**: 시세나 재무지표 자동조회가 실패하면 "🔍 검색해서 찾기" 링크가 나타나 국내는 Naver, 해외는 Google에서 해당 종목을 바로 검색해줍니다. 종목 상세 영역에는 항상 Naver Finance(국내)·Yahoo Finance(해외) 원본 페이지로 바로가는 링크도 있어, 값을 확인해서 직접 입력하기 편합니다.
- **환율 자동조회**: Frankfurter(ECB 기준) 공개 엔드포인트로 USD→KRW 환율을 자동 조회하며, 실패 시 직접 입력합니다.
- **배당금 계산**: 보유 수량 × 주당 연간 배당금을 선택한 지급월에 균등 분배해 월별·연간 예상 배당금을 계산하고, 국내/해외 스택형 막대그래프와 월별 상세표로 보여줍니다. "세후 금액으로 표시"를 켜면 국내 15.4% / 해외 15% 원천징수를 가정한 근사치를 보여줍니다.
- **저장**: 입력한 모든 데이터는 이 브라우저의 localStorage에만 저장되며 서버로 전송되지 않습니다.

## 자동조회 3단계 (모두 무료, API 키 불필요)

종목의 시세·재무지표는 아래 순서로 조회를 시도합니다. 앞 단계가 성공하면 뒤 단계는 호출하지 않습니다.

1. **`data.json` 사전 캐시** (선택 — 가장 빠르고 안정적) — 아래 "정적 데이터(yfinance + GitHub Actions)" 참고.
2. **백엔드 서버(Worker)** (선택) — 아래 "백엔드" 참고.
3. **브라우저 직접 호출** (기본값, 항상 동작) — 브라우저가 Yahoo Finance/Naver Finance 공개 엔드포인트를 직접 호출합니다. 서버가 필요 없지만, 브라우저 CORS 정책이나 네트워크 환경에 따라 가끔 실패할 수 있고 실패 시 직접 입력하면 됩니다.

### 정적 데이터 (yfinance + GitHub Actions, 선택)

`scripts/update_data.py`는 파이썬의 무료 비공식 Yahoo Finance 래퍼 라이브러리인 [`yfinance`](https://github.com/ranaroussi/yfinance)로 `scripts/tickers.json`에 등록된 감시 목록의 시세·PER·PBR·배당성향·부채비율·(가능하면) 총자산을 가져와 저장소 루트의 `data.json`에 저장합니다. `.github/workflows/update-data.yml`이 매 시간 자동으로 이 스크립트를 실행하고 결과를 커밋합니다(수동 실행도 가능: GitHub 저장소의 **Actions → Update market data → Run workflow**).

`index.html`은 페이지를 열 때 같은 저장소에 있는 `data.json`을 **같은 출처(same-origin)** 로 불러옵니다. 브라우저 CORS 제약이 전혀 없고, 네트워크 호출 자체가 필요 없어 가장 빠르고 안정적입니다. 감시 목록에 없는 종목은 자동으로 2·3단계로 넘어갑니다.

내 포트폴리오 종목을 이 방식으로 미리 갱신해두고 싶다면 `scripts/tickers.json`에 `{ "market": "KR"|"US", "exchange": "KS"|"KQ"(국내만), "ticker": "...", "name": "..." }` 형태로 추가하고 커밋하면, 다음 워크플로 실행부터 `data.json`에 포함됩니다.

### 백엔드 (Cloudflare Workers, 선택)

`worker/index.js`는 같은 무료 공개 엔드포인트(Yahoo Finance, Naver Finance, Frankfurter)를 **서버에서 대신 호출**해주는 선택적 백엔드입니다. 서버끼리의 요청은 브라우저 CORS 제약을 받지 않기 때문에 브라우저 직접 호출보다 안정적으로 동작하고, 시세+재무지표를 한 번의 요청으로 취합해서 돌려줍니다. `data.json`에 없는(감시 목록 밖의) 종목에 특히 유용합니다. API 키는 전혀 필요 없습니다.

배포 방법 (무료, 신용카드 불필요, 약 2분):

1. [Cloudflare 계정](https://dash.cloudflare.com/sign-up)을 만듭니다(무료).
2. 대시보드에서 **Workers & Pages → Create → Create Worker**를 선택하고, 이름을 정한 뒤 **Deploy**를 누릅니다(기본 템플릿이 배포됩니다).
3. 방금 만든 Worker의 **Edit code**로 들어가서, 기존 코드를 모두 지우고 이 저장소의 `worker/index.js` 내용을 붙여넣은 뒤 **Deploy**합니다.
4. Worker 상세 페이지에 표시되는 주소(`https://<워커이름>.<계정이름>.workers.dev`)를 복사합니다.
5. 배당 포트폴리오 트래커 사이트의 "환율 & 시세 설정" 카드에 있는 **"백엔드 서버 URL"** 입력란에 그 주소를 붙여넣습니다. 이 값도 브라우저의 localStorage에만 저장됩니다.
6. 이후 `data.json`에 없는 종목의 시세·재무지표·검색·환율 조회가 이 Worker를 거쳐 이뤄집니다. 입력란을 비우면 언제든 브라우저 직접 호출 방식으로 되돌아갑니다.

## 참고

- 시세·환율·재무지표 자동조회는 모두 무료 공개 엔드포인트를 best-effort로 호출합니다. 외부 API가 정책을 바꾸거나 일시적으로 막히면 조회가 실패할 수 있으니, 그런 경우 표/상세 패널에서 직접 값을 입력하세요.
- 배당금 계산은 단순 추정치이며, 세후 표시도 단순 근사치입니다. 실제 투자 판단은 증권사 앱 등 공식 정보로 확인하세요.
