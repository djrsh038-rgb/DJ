# 다국어 번역기 (실시간 · 무료, GitHub Pages용)

API 키나 토큰 비용 없이, 누구나 바로 쓸 수 있는 실시간 번역 웹페이지입니다.

## 배포 방법

1. GitHub에 새 저장소(Public)를 만듭니다.
2. 이 폴더의 `index.html`을 저장소 루트에 업로드합니다.
3. 저장소 **Settings → Pages**에서 브랜치를 `main`(또는 `master`) / `/root`로 설정 후 저장합니다.
4. 1~2분 후 `https://<사용자이름>.github.io/<저장소이름>/` 주소가 생성됩니다. 이 링크를 공유하면 누구나 로그인/키 입력 없이 바로 사용할 수 있습니다.

## 특징

- **토큰/API 키/비용 전혀 없음** — 무료 공개 번역 엔진(MyMemory Translated API)만 사용합니다.
- **실시간 자동 번역** — 한국어를 입력하다가 약 0.9초 멈추면 자동으로 번역이 갱신됩니다. 버튼을 누를 필요 없이 계속 수정하면서 결과를 바로 확인할 수 있습니다.
- 엑셀에서 한국어 셀 여러 개를 복사해 붙여넣으면 자동으로 여러 행으로 나뉩니다.
- 언어별 글자수 제한 설정 가능 (초과 시 "…"으로 자동 잘림 — AI 재작성은 아닙니다).
- 완료 후 한국어/English/Tiếng Việt/简体中文 시트로 나뉜 .xlsx 파일 다운로드.

## 참고

- 무료 API라 사용량 제한이 있습니다 (익명 기준 하루 약 5,000단어). 사용량이 많다면 `index.html`의 `translateOne` 함수 안 요청 URL 끝에 `&de=본인이메일@example.com`을 추가하면 한도가 늘어납니다.
- 번역 품질은 규칙 기반 기계번역 수준으로, AI 번역보다는 단순합니다. AI 품질과 실시간 갱신이 함께 필요하고 비용을 감수할 수 있다면, 이전에 드린 "AI 실시간 버전"(각자 Anthropic API 키 입력)을 사용하세요.
