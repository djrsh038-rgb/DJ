# 💰 배당 포트폴리오 트래커 (무료, GitHub Pages용)

API 키나 서버 없이, 국내·해외 주식/ETF 배당 포트폴리오를 관리하는 웹페이지입니다.

## 배포 방법

1. GitHub에 새 저장소(Public)를 만듭니다.
2. 이 폴더의 `index.html`을 저장소 루트에 업로드합니다.
3. 저장소 **Settings → Pages**에서 브랜치를 `main`(또는 `master`) / `/root`로 설정 후 저장합니다.
4. 1~2분 후 `https://<사용자이름>.github.io/<저장소이름>/` 주소가 생성됩니다. 이 링크를 공유하면 누구나 로그인/키 입력 없이 바로 사용할 수 있습니다.

## 특징

- **종목 검색으로 데이터 자동 취합**: 회사명이나 티커를 검색창에 입력하면 Yahoo Finance 검색 엔드포인트로 국내·해외 종목을 함께 찾아주고, 결과를 클릭하는 즉시 시세·PER·PBR·주당배당금을 조회해 입력 필드에 자동으로 채워 넣습니다. 검색이 안 되면 필드에 직접 입력해도 됩니다.
- **국내·해외 종목 관리**: 코스피/코스닥, 미국 시장의 주식·ETF를 함께 등록하고 보유 수량을 입력합니다.
- **시세 자동조회**: Yahoo Finance 공개 엔드포인트로 현재가를 자동 조회합니다(국내는 `.KS`/`.KQ` 접미사 사용). 수동 새로고침, 30초/1분/5분 자동 갱신을 지원합니다.
- **재무지표 자동조회**: 종목 추가 시 함께 채워집니다.
  - 국내: Naver Finance 공개 요약 API로 PER·PBR·주당배당금 자동조회
  - 해외: Yahoo Finance 공개 API로 PER·PBR·배당성향·부채비율(가능한 경우 총자산까지) 자동조회
  - 국내 종목의 배당성향·부채비율·총자산은 무료 자동조회 소스가 없어 종목 "상세" 영역에서 직접 입력합니다.
  - 자동조회가 실패하면(브라우저 정책, API 상태 변화 등) 언제든 표에서 직접 값을 입력/수정할 수 있습니다.
- **환율 자동조회**: Frankfurter(ECB 기준) 공개 엔드포인트로 USD→KRW 환율을 자동 조회하며, 실패 시 직접 입력합니다.
- **배당금 계산**: 보유 수량 × 주당 연간 배당금을 선택한 지급월에 균등 분배해 월별·연간 예상 배당금을 계산하고, 국내/해외 스택형 막대그래프와 월별 상세표로 보여줍니다. "세후 금액으로 표시"를 켜면 국내 15.4% / 해외 15% 원천징수를 가정한 근사치를 보여줍니다.
- **저장**: 입력한 모든 데이터는 이 브라우저의 localStorage에만 저장되며 서버로 전송되지 않습니다.

## 참고

- 시세·환율·재무지표 자동조회는 모두 무료 공개 엔드포인트를 best-effort로 호출합니다. 외부 API가 정책을 바꾸거나 일시적으로 막히면 조회가 실패할 수 있으니, 그런 경우 표/상세 패널에서 직접 값을 입력하세요.
- 배당금 계산은 단순 추정치이며, 세후 표시도 단순 근사치입니다. 실제 투자 판단은 증권사 앱 등 공식 정보로 확인하세요.
