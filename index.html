💰 배당 포트폴리오 트래커

국내·해외 주식/ETF를 한곳에 모아 시세와 재무지표를 확인하고, 실제 보유 수량 기준으로 연간·월별 예상 배당금을 계산합니다. API 키나 서버 없이 브라우저에서만 동작하며, 입력한 데이터는 이 브라우저에만 저장됩니다(다른 기기와 공유되지 않음).

환율 & 시세 설정

종목 추가 카드의 검색창에 회사명/티커를 입력하면 국내·해외 종목을 함께 찾아주고, 선택하는 즉시 시세·재무지표를 조회해 자동으로 취합·입력합니다. 조회는 3단계로 시도됩니다: ① data.json 사전 캐시(감시 목록에 등록된 종목이면 GitHub Actions가 yfinance로 미리 갱신해둔 값을 same-origin으로 즉시 사용, 배당성향·부채비율까지 포함 가능) → ② 위 "백엔드 서버 URL"에 배포한 Cloudflare Worker(설정한 경우) → ③ 브라우저에서 Yahoo Finance/Naver Finance 공개 엔드포인트 직접 호출(기본값, 무료·서버 없음이지만 가끔 실패 가능). 각 단계는 자세한 배포 방법이 README에 있습니다.
